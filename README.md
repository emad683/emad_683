# Emad Ahmed - Portfolio 📄✈️

A unique paper-themed developer portfolio crafted with **React 19**, **Tailwind CSS v4**, and **Vite**.

## ✨ Features

- **Paper Aesthetic Design**: Custom crumpled and folded paper effects, torn edges, and realistic shadows.
- **Interactive Origami & Animations**: Paper-crumple theme switch animation, paper plane trajectories, and folded-ear cards.
- **Dark / Light Modes**: Smooth transitions with customized textures for both themes.
- **Featured Sections**:
  - **Hero**: Bio & profile card with hand-crafted paper styling.
  - **About**: Interactive feature highlights and story.
  - **Skills**: Compact paper-note skills with FontAwesome and brand icons.
  - **Projects**: Project showcase with folded-corner cards.
  - **Certificates (Edu)**: Category accordion with full-resolution certificate preview modal.
  - **Contact**: Clean message form with origami plane submit button.
  - **Footer**: Paper stamp links for WhatsApp, LinkedIn, and GitHub.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/emad683/emad.git

# Navigate to project directory
cd emad

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
